# 실습 기자재 무인 대여·반납 모바일 웹

실습 수업 직전에 장비를 두고 온 전공생이 휴대폰으로 공용 보관함의 재고를 확인하고, 학번만 입력해 번호키를 받아 장비를 빌리고 스스로 반납하는 모바일 웹앱입니다. 기획 내용은 [PRD.md](PRD.md)에 있습니다.

## 프로젝트 소개

**문제.** 학과 창고에 남는 장비가 있어도 어디 있는지, 누구에게 말해야 빌리는지 아무도 모릅니다. 그래서 학생은 수업 10~20분 전에 단톡방에 묻다가 답을 못 받고 실습을 포기하거나 사비로 다시 삽니다.

**목적.** 학과에 방치된 공용 기자재를 학생이 즉시 빌리고, 관리자 없이 스스로 반납하게 합니다. 목표는 링크를 열어 번호키를 확인하기까지 90초 안에 끝내는 것입니다.

**범위.** 실습실 1곳의 보관함을 대상으로 재고 조회 → 대여(번호키 확인) → 반납 흐름을 구현했습니다. 로그인과 서버 없이 브라우저에서만 동작합니다.

## 주요 기능

| 화면 | 기능 |
| --- | --- |
| 홈 (`#/home`) | 장비 카드 맨 위에 남은 수량 뱃지와 규격 태그(C타입 등)를 표시합니다. 재고가 0이면 '재고 없음'을 표시하고 대여 버튼을 비활성화합니다. |
| 학번 입력 (`#/rent`) | 입력 칸 안에 형식 안내를 넣고, 틀리면 칸 바로 아래에 틀린 위치를 문장으로 알려 줍니다. 공백과 하이픈은 자동으로 지우고, 오류가 나도 입력한 내용은 그대로 둡니다. 학번 도용 제재, 개인정보 최소 수집, 프로토타입 실습용 안내를 함께 보여 줍니다. |
| 번호키 (`#/key`) | 보관함 위치를 맨 위에, 4자리 번호키를 가장 큰 글자로 보여 줍니다. 캡처해도 된다는 안내가 있고, 학번은 앞 4자리만 표시합니다. 대여 중에는 화면을 나갔다 들어와도 같은 번호키가 보입니다. |
| 반납 (`#/return`) | '장비를 보관함에 넣었다', '보관함을 잠갔다'를 모두 체크해야 '반납 완료' 버튼이 활성화됩니다. 안내는 완료 화면이 아니라 체크리스트 화면에 있습니다. |

그 밖의 기능:

- **재고 유지.** 대여하면 재고가 1 줄고 반납하면 1 늘어납니다. 새로고침해도 유지됩니다.
- **대여 중 배너.** 대여 중이면 홈 맨 위에 '번호키 다시 보기'와 '반납하기' 버튼이 나옵니다.
- **보관함 진입.** 주소 뒤에 `?locker=보관함ID`를 붙이면 그 보관함의 홈이 열립니다(예: `?locker=A1`). 이 주소를 QR에 담아 보관함에 붙입니다.
- **QR 스캔.** 홈의 'QR 스캔' 버튼을 누르면 카메라로 QR을 읽습니다. 카메라를 쓸 수 없거나 권한이 없으면 보관함 코드 입력 칸으로 바뀝니다.

## 실행 방법

**배포 주소:** [배포 주소]

**로컬 실행.** ES 모듈과 `fetch`를 쓰기 때문에 `index.html`을 더블클릭해서 열면 동작하지 않습니다. 프로젝트 폴더에서 로컬 서버를 띄웁니다.

```
python -m http.server 8080
```

브라우저에서 `http://localhost:8080` 을 엽니다. 설치나 빌드 과정은 없습니다.

**처음 상태로 되돌리기.** 재고와 대여 기록은 브라우저에 저장됩니다. 개발자 도구 콘솔에서 `localStorage.clear()`를 실행하고 새로고침하면 예시 데이터로 돌아갑니다.

**로직 점검.** Node.js가 있으면 재고·대여·반납과 학번 검사 로직을 점검할 수 있습니다.

```
node tests/store.check.mjs
```

## 사용 기술

- HTML, CSS, JavaScript(ES 모듈). 프레임워크와 빌드 도구는 쓰지 않았습니다.
- 해시 라우팅 (`#/home`, `#/rent`, `#/key`, `#/return`)
- 초기 데이터는 `data/`의 JSON 파일, 바뀌는 상태(남은 수량, 대여 기록)는 localStorage
- QR 읽기는 브라우저 내장 BarcodeDetector API, 지원하지 않는 브라우저(아이폰 등)에서는 [jsQR](https://github.com/cozmo/jsQR) 1.4.0 (Apache-2.0, 파일을 저장소에 포함)
- GitHub Pages 배포 (main 브랜치 루트)

```
index.html
css/style.css        화면 스타일과 색상 변수
js/app.js            해시 라우터
js/store.js          재고와 대여 상태, localStorage 저장
js/config.js         학번 형식 기준(숫자 8자리)
js/student-id.js     학번 정리·검사·가리기
js/home.js           홈 화면
js/rent.js           학번 입력 화면
js/key.js            번호키 화면
js/return.js         반납 화면
js/qr.js             QR 스캔
js/vendor/jsQR.js    QR 해석 라이브러리(외부 코드)
js/dom.js            요소 생성 도우미
data/lockers.json    보관함 예시 데이터
data/equipment.json  장비 예시 데이터
tests/store.check.mjs
```

## 한계와 이후 과제

**한계**

- **서버가 없습니다.** 재고와 대여 기록이 각자의 브라우저에만 저장되어 기기 사이에 재고가 맞춰지지 않습니다. 다른 휴대폰에서 열면 항상 처음 수량으로 시작합니다.
- **실물 보관함이 없습니다.** 번호키는 예시 값이고, 실제 잠금은 화면의 안내와 체크로만 확인합니다. 체크만 하고 잠그지 않는 것은 화면으로 막을 수 없습니다.
- **학번 도용을 막을 수 없습니다.** 로그인 없이 학번의 자릿수와 숫자 여부만 검사합니다. 타인의 학번을 입력해도 대여되며, 제재 안내 문구로만 대응합니다.
- **QR 스캔은 https 주소에서만 됩니다.** 브라우저가 https가 아닌 주소에는 카메라를 허용하지 않아, 그런 경우 보관함 코드 입력으로 대체됩니다.
- **데이터가 예시입니다.** 보관함 위치 문구, 번호키, 장비 종류와 수량, 학번 자릿수는 확인 전의 값입니다.

**이후 과제**

- 테스트 참여자 6명으로 지표 3가지를 실측합니다: 장비 확보 소요 시간(목표 90초 이내), 학번 입력 오류 후 전체 삭제 횟수, 반납 잠금 안내 인지 비율.
- 학번 형식, 보관함 위치 문구와 번호키, 장비 종류와 수량을 실제 값으로 바꿉니다.
- PRD에서 선택 기능으로 둔 케이블 호환 추천(F10)과 측정 모드(F11)는 구현하지 않았습니다.
- PRD에서 범위 밖으로 둔 항목은 후속 과제로 남습니다: 학사 계정 연동, 도어락 자동 개폐, 연체 관리, 관리자 화면, 서버 연동과 기기 간 재고 동기화.
